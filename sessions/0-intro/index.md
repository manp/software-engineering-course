# جلسه ۰ — مفاهیم پایه

📅 **موضوع جلسه:** شروع مسیر مهندسی نرم‌افزار — بدهی فنی، چرخه حیات توسعه و متدولوژی‌ها

## 🎯 اهداف جلسه
- درک مفهوم **بدهی فنی** و تأثیر آن بر پروژه‌های واقعی
- آشنایی با **چرخه حیات توسعه نرم‌افزار (SDLC)** و فازهای آن
- شناخت **متدولوژی‌های توسعه** و انتخاب روش مناسب برای هر پروژه
