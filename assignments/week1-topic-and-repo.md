# تمرین پروژه — هفتهٔ ۱: انتخاب موضوع و ساخت رپازیتوری

📅 **مهلت:** جمعه ۲۴ مهر ۱۴۰۵، ساعت ۲۳:۵۹ (16 Oct 2026)

## 🎯 هدف

موضوع پروژهٔ ترم خود را انتخاب کنید، رپازیتوری عمومی آن را بسازید، فایل `README.md` را با توضیح اولیهٔ ویژگی‌های محصول بنویسید و لینک رپازیتوری را در ربات تحویل دهید.

## 📋 مراحل

1. **انتخاب موضوع**
   - از [فهرست موضوع‌های پیشنهادی](../projects/topics.md) یک موضوع انتخاب کنید؛ یا
   - موضوع دلخواه خود را با استاد مطرح کنید و پس از تأیید شروع کنید.

2. **ساخت رپازیتوری عمومی**
   - در GitHub یک مخزن جدید با نام مناسب (مثلاً نام محصول) به‌صورت **Public** بسازید.
   - در طول ترم، همهٔ مستندات پروژه (تحلیل، طراحی، مستندات) در همین مخزن قرار می‌گیرد.

3. **نوشتن `README.md`**
   در مخزن خود فایل `README.md` بسازید و این بخش‌ها را بنویسید:
   - نام محصول و توصیف یک‌خطی
   - مسئله/نیازی که محصول حل می‌کند
   - ویژگی‌های اصلی محصول (لیست)
   - مخاطب‌های محصول
   - فناوری‌های اولیهٔ پیشنهادی
   - نقشهٔ راه ساده (اختیاری)
   - می‌توانید از [قالب README](../projects/templates/README-template.md) استفاده کنید.

4. **تحویل در ربات**
   - تا جمعهٔ شب، یک **فایل متنی** (`txt` یا `md`) بسازید و لینک رپازیتوری خود را داخل آن بنویسید.
   - فایل را در ربات درستیار @darstyar_bot از مسیر «📤 ارسال تمرین» بفرستید.

## ⚠️ نکته‌ها

- این هفته نیازی به کدنویسی نیست؛ فقط README و لینک رپازیتوری.
- رپازیتوری باید **Public** باشد تا استاد بتواند آن را ببیند.
- این تمرین بخشی از امتیاز پروژهٔ ترم است.
- مهلت، جمعهٔ شب همین هفته است؛ ارسال بعد از مهلت پذیرفته نمی‌شود.
